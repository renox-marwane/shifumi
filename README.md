# Shifumi

Petit jeu pierre-feuille-ciseaux en HTML/CSS/JS, contre l'ordinateur.

## Fonctionnalités

- Choix entre pierre, feuille ou ciseaux
- L'ordinateur joue un coup aléatoire
- Affichage du coup joué par les deux joueurs
- Compteur de victoires / égalités / défaites
- Bouton pour réinitialiser le score
- Responsive (s'adapte au mobile)

## Technologies

- HTML5
- CSS 
- JavaScript 

## Lancer le projet

Ouvrir `index.html` dans un navigateur, c'est tout.
